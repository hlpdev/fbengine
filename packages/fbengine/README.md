# fbengine

A game engine for FutureBlitz: windows and input, 2D, the 3D scene, and a Vulkan renderer that
can look like Blitz3D or like a modern game.

```toml
[dependencies]
fbengine = "0.1"
```

```vb
Import std.core
Import fbengine

Print("fbengine {Version()}")
```

Its sound is `fbengine_audio`, its physics `fbengine_physics`, and its UI `fbengine_ui`, released
with it at the same version. Apache-2.0.
